# 여기에 블렌더 모델을 넣으세요

이 폴더에 아래 파일들을 넣으면 자동으로 사용됩니다. 없으면 대신 기본 박스 모델/단순 벽으로 대체됩니다.

- `desk.glb` — 책상 모델
- `chair.glb` — 의자 모델
- `classroom.glb` — 교실(벽/창문/문/칠판 등) 모델. 없으면 코드로 그린 단순한 벽으로 대체됩니다.

## 블렌더에서 내보내는 방법

1. 모델의 바닥이 **원점(0,0,0)에 붙어있고**, 정면이 **-Z 방향**을 보도록 배치/정렬하세요.
   (자리배치 프로그램은 각 좌석에서 이 방향이 "칠판을 바라보는 방향"이라고 가정합니다.)
2. 실제 크기(미터 단위)와 최대한 비슷하게 스케일을 맞춰주세요. (참고: 책상 약 0.6m × 0.45m, 의자 약 0.4m × 0.4m)
3. 상단 메뉴에서 `File > Export > glTF 2.0 (.glb/.gltf)` 선택
4. Format은 `glTF Binary (.glb)` 로 선택
5. `Transform > +Y Up` 이 체크되어 있는지 확인 (기본값)
6. 내보내기 옵션에서 `Apply Modifiers` 를 체크하면 모디파이어가 적용된 최종 모양으로 저장됩니다
7. 파일 이름을 `desk.glb`, `chair.glb` 로 저장해서 이 폴더(`models/`)에 넣으세요

저장 후 브라우저를 새로고침하면 3D 미리보기에 모델이 반영됩니다. (아래 프로젝트 루트 README.md의 "로컬에서 실행하기" 참고)

## 교실(classroom.glb) 내보내기

교실은 책상/의자와 좌표 기준이 달라요. **가로 7.2m × 세로 7.6m** 기준으로 만들어져 있어야 하고,
칠판이 있는 앞벽 쪽이 원점 부근(Y=0)에서 시작해서 방이 **-Y 방향**으로 뻗어나가는 구조여야
내보냈을 때(+Y Up 기준) 웹사이트의 칠판(z=0) 기준과 정확히 맞습니다.

1. 아웃라이너에서 교실에 해당하는 컬렉션/오브젝트들을 전체 선택
2. `File > Export > glTF 2.0`, Format `glTF Binary (.glb)`, **Selected Objects** 체크, `+Y Up` 체크
3. 파일 이름 `classroom.glb` 로 저장해서 이 폴더에 넣기

사용자가 웹사이트에서 교실 가로/세로 값을 바꾸면, `classroom.glb`를 그 비율만큼 가로/세로 방향으로
늘리거나 줄여서 표시합니다 (7.2m x 7.6m가 원래 크기 100% 기준).

(현재 `classroom.glb`는 실제 블렌더 원본과 축이 달라서, 원본을 복사한 뒤 방향만 맞춰 회전/이동시켜서 내보낸 것입니다. 원본 `.blend` 파일 자체는 수정되지 않았습니다.)
